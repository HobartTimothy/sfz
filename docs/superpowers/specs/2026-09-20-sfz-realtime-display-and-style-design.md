# sfz 实时显示功能与样式优化 — 设计文档

日期：2026-09-20
状态：已确认

## 背景与目标

sfz 是纯浏览器本地的图片水印打码工具（身份证等敏感证件打码），核心原则是**零依赖、无任何网络请求**。当前版本已有"实时刷新"复选框（默认勾选），但参数值不可见、无图片信息展示、页面样式简陋。

本次改动目标：

1. **显示参数当前值** — 拖动滑块时右侧 chip 实时显示数值
2. **始终实时预览** — 删除"实时刷新"复选框与"刷新"按钮，预览永远随参数实时更新
3. **显示图片信息** — 信息栏显示尺寸、文件大小、水印字数
4. **输入时实时预览文字** — 输入水印文字立即反映到预览图
5. **优化样式** — 采用「现代卡片风」重做页面

## 关键决策（已与用户确认）

| 决策点 | 结论 |

## 范围

**做：**
- 删除 `auto-refresh` 复选框与 `refresh` 按钮（始终实时）
- 参数值 chip（颜色 #HEX、透明度、角度、间隔、字号）
- 信息栏卡片（📐 尺寸 / 💾 文件大小 / ✏️ 字数）
- 重写 `public/index.html` 结构与内联 CSS（卡片风）
- 重构 `src/script.coffee` 为清晰的小模块
- 修复现有 bug：`autoRefresh` / `refresh` 监听器在 `inputItems.forEach` 循环中被重复绑定 6 次（删除控件后自然消失）

**不做：**
- 不引入任何依赖、框架、构建工具（保持 `cake build`）
- 不改变下载文件名生成规则（时间戳 PNG）
- 不改 gif 只取第一帧的现有限制
- 不做本地存储（localStorage 记忆设置）、暗色模式、多语言

## 页面结构与样式

```
容器 max-width 560px 居中，浅灰蓝背景 #f5f7fa
├─ 头部：蓝色 logo 方块 + 标题「图片水印打码工具」+ 简介（保留 GitHub 链接）
├─ 卡片 1「① 选择图片」：文件选择控件
├─ 卡片 2「② 水印设置」：
│    文字输入框
│    颜色选择器 + #HEX 值标签
│    4 个滑块行（透明度/角度/间隔/字号），每行 = 标签 | 滑块 | 值 chip
├─ 信息栏卡片：📐 尺寸 | 💾 文件大小 | ✏️ 字数（三列均分）
└─ 卡片 3「③ 点击图片下载」：canvas 预览，虚线边框，悬停显示"点击下载"提示
```

样式 tokens：

- 主色 `#2563eb`，背景 `#f5f7fa`
- 卡片：白底、圆角 10px、轻阴影（`0 1px 3px rgba(0,0,0,.08)`）
- 值 chip：浅蓝底 `#eff6ff` + 蓝字 `#2563eb`，圆角 4px，等宽数字
- 步骤徽章：蓝色圆形小数字
- 移动端 ≤560px：卡片自适应全宽，滑块行保持三列布局
- CSS 全部内联在 index.html（零外部资源）

## 行为与数据流

### 模块划分（script.coffee 重构）

1. **状态** — 集中管理 `canvas`、`img`、`textCtx` 引用
2. **渲染管线** — `drawText()`（旋转 + 平铺水印，保留现有算法）+ `scheduleRender()` 防抖入口
3. **值标签更新** — `updateValueLabels()`
4. **信息栏更新** — `updateInfoBar()`
5. **图片加载** — 现有 `readFile()` 逻辑保留
6. **下载** — 现有 canvas 点击下载逻辑保留（含时间戳文件名）

### 事件流

```
任意 input 事件（滑块 / 文字 / 颜色）
  ├─ 立即：更新值 chip（DOM 文本，极廉价 → 数字即时跳）
  ├─ 立即：更新 ✏️ 字数（text.length）
  ├─ 防抖 120ms + rAF：重绘 canvas（底图 + 水印）
  └─ 防抖 500ms：toDataURL 实测字节数 → 更新 💾 文件大小
```

设计理由：

- 值 chip 不等待重绘，拖动滑块时数字流畅跳动
- canvas 重绘昂贵（大图 + 数百次 fillText），120ms 防抖 + rAF 合并连续事件，避免卡顿
- 💾 大小用 `canvas.toDataURL('image/png')` 实测字节数（与下载文件的编码完全一致，因此是精确值而非估算），最重的操作给最长防抖，停止操作 500ms 后计算一次
- 📐 尺寸在图片加载完成时显示 `W × H px`；未选图时信息栏显示「—」

## 错误处理与边界情况

| 场景 | 行为 |
|------|------|
| 未选图片 | 信息栏占位「—」；参数可正常调整（chip 正常更新）不报错；选图后立即渲染 |
| 非法文件类型 | 保留现有 alert「仅支持 png, jpg, gif 图片格式」 |
| 空文字 | 只绘底图（无水印），下载即原图 |
| 超长文字 | 保留 maxlength 30 |
| gif | 取第一帧（现有限制，保持） |
| 颜色非法值 | 正则匹配失败时回退默认蓝色 |
